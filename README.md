# dia4-python
No Dia 4, avancei nos estudos de Python resolvendo os exercícios 16 ao 27 do Curso em Vídeo. Aprendi a trabalhar com módulos externos como math, random e pygame, além de aprofundar a manipulação de strings e números. Pratiquei decomposição de valores, sorteios, ordenações, análise de nomes e frases, e até execução de arquivos de áudio.
